## Release Version Bump

For each Google Play update, run:

```bash
./scripts/bump_release_version.sh
```

This updates `pubspec.yaml` from `MAJOR.MINOR.PATCH+BUILD` to
`MAJOR.MINOR.(PATCH+1)+(BUILD+1)`.

Example:
- `1.0.3+6` -> `1.0.4+7`
