## 2. Kern-Architektur

```
main.dart              → MaterialApp + Routes + global appLocale (ValueNotifier)
theme/app_theme.dart   → AppColors (const) + AppTheme.dark (static ThemeData)
services/alarm_service → Singleton, SharedPreferences-Backend, AudioPlayer
screens/               → HomeScreen, AlarmActiveScreen, SettingsScreen, InfoScreen
widgets/bottom_nav.dart→ AppBottomNav (currentIndex) + _NavItem
l10n/                  → generated AppLocalizations
```

**State-Management:**
- Singleton `AlarmService` (factory + `_instance`) — mutable `_isActive`, `_previousVolume`.
- SharedPreferences: `locale`, `alarm_sound`, `custom_sound_path`, `vibration_enabled`, `wakelock_enabled`.
- Screens read prefs async in `initState`/`setState` — race-prone.
- `HomeScreen` observer `WidgetsBindingObserver` + `Timer.periodic(1s)` for clock.
- `AlarmActiveScreen` 2x `AnimationController` (`flash`, `pulse`) + `GestureDetector` stop.

## 3. Stärken

1. **Theme-System** — `AppColors` const + `AppTheme.dark` static getter: clean, no magic numbers in screens.
2. **l10n** — proper `flutter_localizations` + generated `AppLocalizations.of(context)!` in every screen.
3. **Route-Map** — `routes: {'/': ..., '/settings': ..., '/info': ...}` — clean, no `switch`-Hacks.
4. **Singleton Service** — `AlarmService()` factory pattern: one AudioPlayer, one wakelock state.
5. **Animation-Controllers** — `vsync` via `SingleTickerProviderStateMixin`/`TickerProviderStateMixin`, `dispose()`-Cleanup.
6. **WidgetsBindingObserver** — `didChangeAppLifecycleState` handles resume/pause for wakelock.
7. **`flutter analyze` clean** — 0 warnings, 0 infos.
8. **`flutter_launcher_icons`** — adaptive icon config in pubspec.
9. **`flutter_localizations` + `intl`** — proper i18n setup, not hand-rolled.
10. **`flutter_volume_controller`** — restores previous volume on deactivate.

## 4. Schwachstellen / Code Smells

### 4.1 Dead Dependency
- `flutter_ringtone_player: ^4.0.0` — **0 usages** in `lib/`.
- `cupertino_icons: ^1.0.8` — **0 usages** (Material-Icons used).
- `intl: ^0.20.2` — only via `flutter_localizations`, not directly.

### 4.2 Singleton-Service: mutable state, no dispose
- `AlarmService._instance` is `static final` — `_player.dispose()` never called.
- `_previousVolume` is nullable, but `deactivate()` reads `_previousVolume!` — race if `activate()` throws before set.
- Singleton survives across route changes; no lifecycle hook.

### 4.3 SharedPreferences: no schema, no migration
- Keys: `locale`, `alarm_sound`, `custom_sound_path`, `vibration_enabled`, `wakelock_enabled` — no versioning.
- `alarm_sound` stored as `int` index — fragile if enum order changes.
- No `SharedPreferences` sync/flush — `setX` without `await` in some paths.

### 4.4 `GestureDetector` without `behavior`
- `bottom_nav.dart:72` — `GestureDetector(onTap: onTap, child: Column(...))` — no `HitTestBehavior.opaque`.
- `home_screen.dart:192` — same pattern.
- `alarm_active_screen.dart:186` — same.
- `settings_screen.dart:270` — same.
- **Risk:** invisible padding areas may not register taps.

### 4.5 `Navigator.pushReplacement` with `MaterialPageRoute`
- `home_screen.dart:73` — `pushReplacement(MaterialPageRoute(builder: ...))` — **deprecated** in Flutter 3.x.
- `alarm_active_screen.dart:54` — same.
- `bottom_nav.dart:36-48` — `pushNamed` / `pushReplacementNamed` — inconsistent.

### 4.6 `Timer.periodic` for clock
- `home_screen.dart:31` — `Timer.periodic(1s)` + `setState` — **anti-pattern**.
- Better: `DateTime.now()` in `build()` or `Text('...')` with `TextSpan` + `TextEffect`.

### 4.7 `AppBottomNav` currentIndex
- `currentIndex: 0/1/2` — magic numbers, no enum.
- `onTap` logic: `currentIndex == 0 ? () {} : () => Navigator.pop()` — nested ternary, hard to read.

### 4.8 `SettingsScreen` async setState
- `_loadSettings()` in `initState()` — async, but `setState` called after `await` — race with first `build()`.
- `_selectSound` / `_pickCustomSound` — `setState` after `await` — race with user-tap.

### 4.9 `InfoScreen` async version
- `PackageInfo.fromPlatform().then(...)` in `initState` — no `await`, no error handling.

### 4.10 `main.dart` global `appLocale`
- `final ValueNotifier<Locale?> appLocale = ValueNotifier(null);` — global mutable state.
- `settings_screen.dart:199` — `appLocale.value = Locale(code)` — writes global from screen.

### 4.11 `flutter_ringtone_player` unused
